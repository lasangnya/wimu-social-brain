# Caption guide

Structure every caption: hook -> value -> CTA.

1. Hook: one line that stops the scroll. It must land before the fold (~125 chars on Instagram, ~210 on LinkedIn).
2. Value: 1-5 short lines — the point, the proof, the how. One idea per post; proof points from brand.md make the strongest value lines.
3. CTA: the primary call to action from brand.md, on its own line. Secondary only if it costs one line.

Write to one person from the brand.md audience, in the brand.md voice — the example lines there outrank the adjectives.

## Instagram

- Length: well under the 2,200-char limit; 3-8 short lines is usually right.
- Tone: warm, direct, visual-first.
- Emoji policy: allowed — 0-5 per caption as emphasis or bullet markers (e.g. ✅ or 👇), never mid-word, never replacing a word. Skip them entirely when brand.md's voice says so.
- Hashtags: up to 30. Mix brand.md's brand tags with broad-reach and niche topic tags; block them at the end of the caption under a blank line.

## LinkedIn

- Length: up to ~3,000 chars, but earn the click in the first two lines.
- Tone: professional, specific, no hype; short paragraphs.
- Emoji policy: sparing — 0-2 per post, only where a plain word would do the same job (e.g. an arrow → for a pointer). When in doubt, none.
- Hashtags: 3-5, professional and topic-relevant; brand tags first.

## Carousels

One caption for the whole carousel — Instagram and LinkedIn carousels have a single caption, never one per slide. The caption still runs hook -> value -> CTA: its hook must match slide 1 (the only slide guaranteed to be seen) and its CTA should match the last slide. The per-slide headlines are listed by the skill in `captions.md` for reference; they are not separate captions.

## Alt text

One or two sentences: what the image shows plus the point it makes. Describe the focal action, name the mascot if there is one, and include the baked headline verbatim. Never start with "image of".

## Do / Don't

Do:

- Put the CTA on its own line.
- Reuse proof points as value lines.
- Match brand.md's example lines before matching its adjectives.
- Keep the first line under the fold limit with the point already made.

Don't:

- Hashtag-spam LinkedIn, or stack all 30 Instagram tags when 8 fit better.
- Engagement bait ("comment YES", "tag a friend").
- Buzzwords or topics on brand.md's avoid list.
- More than one idea per post.
- A CTA that is not in brand.md, unless the user asked for it.
