# Style DNA

## In one sentence

Pure white, minimal, hand-drawn, whitespace, restrained, absurd, product-sketch feel, handwritten feel, clear structure but not a manual.

Like someone who has long worked on AI, product, design and dev tools, casually sketching an explanatory drawing on a blank sheet of paper.

## Must

- 16:9 landscape body illustration (2048x1152 preferred).
- Pure white background: no beige, warm gray, paper texture, gradient, shadow, noise, vintage-paper feel.
- Mostly black hand-drawn line art: thin lines, slight wobble, not mechanical, not vector, no heavy outlines.
- Lots of whitespace: subject occupies ~40-60% of the canvas, at least 35% blank, ideally one whole quiet area.
- One image tells only one core action, structure, state or metaphor.
- Structure should be expressed naturally; never write the structure-type name on the image.
- **No text inside the image.** Labels are added afterwards in the configured font. Ask for clear empty space next to each key object for a label.

## Colors

- Black: main line art, the mascot, frames, structure, main objects.
- `flow`: main path, arrows, automation direction, movement from A to B.
- `warn`: key annotations, problems, emotional points, key reminders, results.
- `note`: supplementary notes, in-head state, system state, second-layer explanation, AI/assistant/automation hints.

Colors and their hex values come from `wimu-social-brain.md`. `note` is not required in every image. Be restrained with color; fewer is better.

## Absolutely not

- No commercial illustration.
- No PPT infographics.
- No formal flowcharts.
- No course slides.
- No cute cartoon posters.
- No children's illustration.
- No complex architecture diagrams.
- No polished flat illustration.
- No techy UI.
- No real app screenshots.
- No complex backgrounds, gradients, shadows, textures.
- Don't explain every node.
- Don't write type-titles like "Workflow / System Architecture / Common Pitfalls / Roadmap" in the top-left.

## Aesthetic direction

Be absurd, creative, interesting, clean and simple, wildly imaginative.

Not cute, not childish, not complex, not rigid.
